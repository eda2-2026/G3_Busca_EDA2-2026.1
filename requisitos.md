## Requisitos Funcionais

RF1 - O sistema deve carregar um dicionário de palavras
RF2 - O sistema deve armazenar palavras em uma BST
RF3 - O sistema deve permitir buscar palavras digitadas
RF4 - O sistema deve sugerir palavras que começam com determinado prefixo
RF5 - O sistema deve sugerir correção quando a palavra não existir

## Requisitos não-funcionais

RNF1 - Latência de busca deve ser baixa
RNF2 - Código modular
RNF3 - Projeto versionado no GitHub
RNF4 - Documentação clara no README
